# MusicRecPlus 🎵

A **Python music recommendation system** that stores user preferences, suggests new artists based on similar users, and tracks the most popular artists in the database.  
Originally developed as a class project and expanded with additional features for personalization and analysis.  

## Features
- Save and update favorite artists for each user.
- Personalized recommendations by comparing similarity across users.
- View the **top 3 most popular artists** in the system.
- See like counts for the most popular artist.
- Identify the user who likes the most artists overall.
- Privacy mode with `$` suffix to anonymize usernames.
- Data stored locally in `musicrecplus.txt`.

## Menu
When running the program, you can select from the following options:

e - Enter preferences
r - Get recommendations
p - Show most popular artists
h - How popular is the most popular
m - Which user has the most likes
q - Save and quit

## Tech Stack
- **Language:** Python 3  
- **Storage:** Local text file (`musicrecplus.txt`)
