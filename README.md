MusicRecPlus is a Python music recommendation system that stores user preferences, suggests new artists based on similar users, and tracks the most popular artists in the database.

Features:
Save and update favorite artists
Personalized artist recommendations based on similarity
View top 3 most popular artists
See like counts for the most popular artist
Find the user who likes the most artists
Privacy mode with $ suffix for usernames
Data stored locally in musicrecplus.txt


How to run:
python3 musicrecplus.py


Menu:

e - Enter preferences  
r - Get recommendations  
p - Show most popular artists  
h - How popular is the most popular  
m - Which user has the most likes  
q - Save and quit
